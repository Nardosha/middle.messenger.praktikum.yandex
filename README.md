# Учебный проект: мессенджер!

Веб-приложение для обмена текстовыми, аудио- и видео-сообщениями.

## О проекте:
Проект реализован на стеке:  Typescript, Vite, Handlebars, SASS. Архитектура отдаленно напоминает FSD.

За основу дизайна взят макет от ME Studio. [Ссылка на макет](https://www.figma.com/design/ynuMbk5OF4WvUvQpgq3ZWb/Chat-Messenger?m=auto&t=Az8rNbujeRwso16w-1)


## Цель проекта:
Проект написан с целью освоения и улучшения работы с шаблонизатором, веб-сокетами и TypeScript. А также для ознакомления с FSD архитектурой.

## Команды, используемые в проекте
-   `npm install`  — установка зависимостей;
-   `npm run dev`  — запуск проекта в режиме **dev**;
-   `npm run preview`  — запуск предпросмотра;
-   `npm run build`  — сборка стабильной версии;
-   `npm run start`  — сборка стабильной версии и предпросмотр;
